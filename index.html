Tu idea de la libreta ![Mockup Técnico](docs/mockup_tecnico.webp) **1. Celular sobre el pecho** El smartphone se coloca en el pecho para que el corazón quede cerca y poder detectar latido. Usa el acelerómetro/giroscopio (sismocardiograma). No necesita internet. **2. Micrófono apuntando al mentón - IMPORTANTE** El micrófono apunta al mentón/barbilla para detectar respiración mediante sonido. Detecta frecuencia y obstrucción. **3. Celular debajo o a un lado de la camilla** Fijo en la estructura, no se mueve con la vibración de la ambulancia. ### 🔧 Hardware - Soporte 3D Imprimible ![Soporte 3D](docs/soporte_3d.webp) - **Material:** PETG o PA-CF (Nylon con fibra de carbono) - Resiste sangre y desinfectante - **Instalación:** Clamp 22-30mm, sin taladrar la camilla - **Brazo:** 80mm, 360° swivel + 45° tilt - **Diseño:** Modular, sin soportes al imprimir Archivo STL en `/hardware/phone_holder_v1.stl` ### 💻 Stack Técnico | Versión | Tecnología | Uso | | --- | --- | --- | | **MVP (actual)** | HTML + JS + Web APIs | Prototipo rápido, PWA offline | | **Pro v2.0** | Kotlin + C++ NDK | `libparamedic.so` - Procesamiento real a 200Hz, sin latencia | ```cpp // Core en C++ - 100% offline bool detectHeartBeat(float ax, ay, az) // vibración pecho bool detectBreath(float audioLevel) // micrófono al mentón ### 🚀 Instalación Rápida git clone https://github.com/tu-usuario/paramedic-offline.git cd paramedic-offline # MVP Web - abre en tu celular open app/paramedic.html ### 📋 Roadmap - Idea en libreta + boceto camilla - Mockup técnico y soporte 3D - MVP HTML funcionando offline - Demo real en dispositivo - [ ] Core en C++ NDK (sensor a 200Hz) - [ ] APK firmada + modo kiosco - [ ] Bitácora SQLite local de paciente[x] ### ⚠️ Disclaimer Herramienta de apoyo para toma de decisiones, no reemplaza equipo médico certificado.
